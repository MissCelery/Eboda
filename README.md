# Eboda

A free PDF reader and editor. Your files never leave your computer.

## What it does

- Read PDFs with search, thumbnails, outline and zoom
- Edit existing text and add new text
- Draw your signature and place it on a page
- Highlight, underline, strike through, sticky notes, pen and shapes
- Fill in forms and redact sensitive content
- Rotate, reorder, delete, insert and extract pages
- Print (Windows app)

## Two ways to use it

Windows app (works offline, can be your default PDF app): go to the Releases page on the right, download Eboda-Setup, and run it. Windows may show a blue "protected your PC" box because the installer is not signed with a paid certificate. Click More info, then Run anyway. The installer is built automatically from the code in this repository (see Actions), and the Release includes a SHA256.txt so you can check that your download matches.

In the browser: open index.html in Chrome or Edge. No install needed. Printing is not available in this version.

## Not included yet

OCR, compression and Word conversion.
